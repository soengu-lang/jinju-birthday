# 우리집 자산 📊

주식·코인·달러·금·부동산·예적금을 **한 번만 담아 두면**, 그 다음부터는 열 때마다
시세가 자동으로 붙어서 **지금 우리 자산이 얼마인지** 한 화면에서 보여줍니다.

종목을 하나하나 검색해서 찾아다닐 필요가 없어지는 게 이 앱의 전부입니다.

앱 파일은 `index.html` **하나**뿐입니다. 서버도, 설치도, 회원가입도 없습니다.

## 네 개의 탭

### 🏠 한눈에
- **순자산**(대출 뺀 금액)과 오늘 얼마나 움직였는지
- 총자산 · 대출 · 원금, 총수익과 수익률
- 목표 금액을 정해 두면 달성률 막대
- 자산 구성 도넛, 순자산 추이(하루 한 번 자동 기록), 오늘 많이 움직인 종목
- 위쪽 **전체 / 진주 / 성우 / 공동** 을 누르면 그 사람 것만 봅니다

### 📈 내 종목
종류별로 묶어서 평가금액·비중·수익률을 보여줍니다.
종목을 누르면 수량·평단을 고치거나, **📊 차트·뉴스 보기**로 네이버증권·업비트로 바로 넘어갑니다.

### ＋ 담기
- **국내주식**은 `삼성전자`, `005930` 처럼 이름이나 코드로
- **미국주식**은 `애플`, `AAPL`, `나스닥100` 처럼 한글 이름으로도
- **코인**은 `비트코인`, `리플` 처럼 한글 이름으로 (업비트 원화마켓 전체)

자주 찾는 종목 **250여 개가 앱 안에 미리 들어 있어서** 인터넷 없이도 바로 뜹니다.
목록에 없으면 이어서 인터넷 검색까지 해 봅니다.

> 담은 뒤에는 실제 종목의 정식 이름이 같이 표시됩니다. 혹시 다른 종목이 담겼으면 바로 알 수 있어요.

### 📋 잔고 붙여넣기 — 여러 종목을 한 번에

＋ 담기 맨 위 **📋 잔고 붙여넣기 → 열기**.
증권사 앱이나 거래소의 **보유 종목 화면을 그대로 복사**해서 붙여넣으면 됩니다.

**증권사마다 형식이 달라도 됩니다.** 정해진 양식을 요구하지 않고,
줄마다 ① 종목처럼 보이는 말 ② 숫자를 찾아낸 뒤
`수량` `평균` `현재가` `평가금액` 같은 단어를 힌트로 삼아 무엇이 무엇인지 가려냅니다.

이런 것들이 모두 됩니다:

```
삼성전자	005930	30	70,000        ← 표를 복사한 경우
카카오
50주
평균 45,000                          ← 줄이 나뉜 모바일 화면
비트코인 BTC

10주 · 평균 $180.00                   ← 미국주식

```

붙여넣으면 **알아들은 결과를 표로** 보여줍니다. 거기서

- 이름 · 수량 · 평균단가 · 코드를 직접 고치고
- 종류(국내/미국/코인/부동산…)를 바꾸고
- 필요 없는 줄은 **체크를 빼면** 됩니다

를 한 뒤 **담기**를 누르면 들어갑니다. 누르기 전엔 아무것도 저장되지 않습니다.

- 명의는 **한 번에 하나**로 정합니다(한 계좌를 통째로 붙여넣는 것이니까요). 나중에 종목별로 바꿀 수 있어요.
- **이미 담아 둔 종목**은 새로 만들지 않고 수량·평단만 바뀝니다 —
  잔고 화면을 다시 붙여넣으면 **현재 상태로 맞춰지는** 셈입니다.
- 앱이 모르는 종목은 인터넷 검색으로 코드를 찾아보고, 그래도 없으면
  ⚠️ 표시와 함께 코드를 직접 적게 합니다.
- 못 알아들은 줄은 **버리지 않고** 아래 «못 알아들은 줄 보기»에 모아 보여줍니다.

> 수수료·주문 내역처럼 잔고가 아닌 화면을 붙여넣으면 엉뚱하게 읽을 수 있습니다.
> 표에서 확인하고 체크를 빼면 됩니다.

## 시세는 어디서 오나요

정적 웹페이지라 서버가 없습니다. 그래서 브라우저가 직접 가져옵니다.

| | 어디서 | 막힐 일 |
|---|---|---|
| 코인 | 업비트 | 거의 없음 |
| 환율 | 두나무 → er-api → 야후 | 거의 없음 |
| 주식·금 | 야후 (공개 중계 서버 경유) | 가끔 있음 |

주식은 브라우저가 야후를 바로 부르지 못해서 **공개 중계 서버**를 순서대로 시도합니다.
한 번 성공한 경로를 기억해서 다음부터는 그것부터 씁니다.

**다 막히면** 마지막으로 받아 둔 시세를 그대로 보여주고 위쪽에 몇 건 실패했는지 알려줍니다.
그럴 땐 종목을 눌러 **시세 직접 입력**에 값을 적으면 됩니다 — 적어 둔 값이 자동 조회보다 우선합니다.

시세는 **앱을 열 때 한 번**, 그리고 보고 있는 동안 **2분마다** 새로 가져옵니다.
🔄 를 누르면 언제든 바로 갱신됩니다.

> 🥇 금은 **국제 시세(달러/트로이온스)를 원/g으로 환산**한 값입니다.
> 한국금거래소 소매가와는 차이가 있으니, 그 값으로 보고 싶으면 직접 입력해 주세요.

## 💑 배우자와 함께 보기

가계부·냉장고 앱과 **똑같은 방식**입니다. 무료 Firebase 프로젝트 하나면 됩니다.

1. ⚙️ → **배우자와 함께 보기**
   가계부나 냉장고 앱을 이미 쓰고 있으면 **버튼 하나로** 같은 Firebase에 연결됩니다.
2. 방 이름을 정하고 **연결하기**
3. **🔗 초대 링크 복사** 해서 배우자에게 보내면, 열자마자 같은 자산 목록을 봅니다.

> 시세는 각자 폰에서 따로 가져오고, **담아 둔 목록과 수량만** 공유됩니다.

## 🧾 가계부 앱과 연동

가계부 앱 **💎 자산** 탭에서 이 앱의 금액을 그대로 불러올 수 있습니다.

- 두 앱을 **같은 폰**에서 쓰면 아무 설정 없이 바로 읽힙니다.
- 다른 폰이라면 두 앱 모두 **같은 Firebase 방**에 연결하면 됩니다.

가계부 자산 탭에 뜨는 `📊 자산 앱` 카드에서 **반영** 을 누르면
그 달 평가액 칸이 자산 앱 금액으로 채워집니다. (누르기 전엔 아무것도 바뀌지 않습니다.)

| 자산 앱 | → | 가계부 자산 항목 |
|---|---|---|
| 국내주식·미국주식 | → | 주식·펀드 |
| 코인 | → | 코인 |
| 부동산 | → | 아파트 / 토지 |
| 예적금·현금 | → | 예적금 / CMA |
| 연금·펀드·기타 | → | 연금펀드/ISA |
| 금·달러 | → | 기타 |

이름으로 자동으로 짝을 맞추고, 마음에 안 들면 직접 고를 수 있습니다.

## 만든 사람을 위한 메모

- 자산 한 줄: `{ id, cat, code, sym, name, owner, qty, avg, avgFx, loan, mp, mpAt, memo }`
- `cat`: `kr` `us` `coin` `gold` `fx` `real` `cash` `etc`
- `mp` 는 직접 입력한 시세. 있으면 자동 조회를 이깁니다.
- 저장 키: `myAssets.v1` · Firestore 경로: `rooms/{room}/assets/core`
  (가계부가 이 경로를 읽습니다. 바꾸면 연동이 끊깁니다.)
- 공유되는 값: `settings` `holdings` `memo` — 시세 캐시와 추이 기록은 폰마다 따로입니다.
