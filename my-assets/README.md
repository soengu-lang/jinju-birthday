# 우리집 자산 📊

주식·코인·달러·금·부동산·예적금을 **한 번만 담아 두면**, 그 다음부터는 열 때마다
시세가 자동으로 붙어서 **지금 우리 자산이 얼마인지** 한 화면에서 보여줍니다.

종목을 하나하나 검색해서 찾아다닐 필요가 없어지는 게 이 앱의 전부입니다.

앱 파일은 `index.html` **하나**뿐입니다. 서버도, 설치도, 회원가입도 없습니다.

## 네 개의 탭 (설정은 오른쪽 위 ⚙️)

### 🏠 한눈에
- **순자산**(대출 뺀 금액)과 오늘 얼마나 움직였는지
- 총자산 · 대출 · 원금, 총수익과 수익률
- 목표 금액을 정해 두면 달성률 막대
- 자산 구성 도넛 — **종류별 / 성격별 / 계좌별** 로 바꿔 볼 수 있습니다
- 순자산 추이(하루 한 번 자동 기록), 오늘 많이 움직인 종목
- 위쪽 **전체 / 진주 / 성우 / 공동** 을 누르면 그 사람 것만 봅니다

### 📈 내 종목
종류별로 묶어서 평가금액·비중·수익률을 보여줍니다.
종목을 누르면 수량·평단을 고치거나, **📊 차트·뉴스 보기**로 네이버증권·업비트로 바로 넘어갑니다.

**증권사 계좌가 여러 곳이어도 한 줄로 보입니다.**
같은 종목을 미래에셋에도, 키움에도 갖고 있으면 (수량·평단이 서로 달라도)
목록에는 `삼성전자 · 계좌 2곳` 한 줄로 합쳐져 나옵니다.

| | 미래에셋 | 키움 | 합쳐서 |
|---|---|---|---|
| 수량 | 30주 | 20주 | **50주** |
| 평균 매수가 | 70,000원 | 85,000원 | **76,000원** |

평단은 **수량으로 가중평균** 합니다 — `(30×70,000 + 20×85,000) ÷ 50 = 76,000`.

그 줄을 누르면 **계좌별로 펼쳐져서** 각 계좌의 수량·평단·수익률을 따로 볼 수 있고,
거기서 계좌 하나만 골라 고칠 수도 있습니다.
계좌 구분이 더는 필요 없으면 **🔗 한 줄로 합치기** 로 진짜 하나로 만들 수 있습니다.

### 세 가지로 나눠 보기

같은 자산을 **보는 축**만 바꾸면 다르게 묶입니다. 홈 도넛과 📈 내 종목 둘 다 됩니다.

| 축 | 무엇으로 묶나 | 이럴 때 |
|---|---|---|
| **종류별** | 국내주식 · 미국주식 · 코인 · 금 · 부동산 … | 기본 |
| **성격별** | 주식 · 채권 · 금·원자재 · 달러 · 부동산 · 현금성 · 코인 | 금을 얼마나 갖고 있나? |
| **계좌별** | 미래에셋 · 삼성 ISA · 신한 IRP · 업비트 … | ISA에 얼마나 넣었나? |

**성격별**이 있는 이유 — 금을 **현물**로도 갖고 **금 ETF**(KODEX 골드선물, GLD)로도 갖고 있으면
종류별로는 `금` 과 `국내주식` 과 `미국주식` 셋으로 흩어집니다.
성격별로 보면 **🥇 금·원자재 하나로** 합쳐집니다. 채권 ETF(TLT·국채)도 마찬가지고요.

이름을 보고 알아서 짐작하지만(골드·GLD·채권·TLT·리츠…), 종목을 눌러 **직접 바꿀 수 있습니다.**

**왜 샀는지, 언제 팔지**를 적어 두는 곳입니다. 안 쓰면 빈 화면이라 부담 없습니다.

- **오늘 한 줄** — 적으면 날짜와 함께 종목에 쌓이고, 일기에도 같이 올라갑니다

**투자 일기** (기록 탭 맨 위)

> 담은 뒤에는 실제 종목의 정식 이름이 같이 표시됩니다. 혹시 다른 종목이 담겼으면 바로 알 수 있어요.

## 시세는 어디서 오나요

정적 웹페이지라 서버가 없습니다. 그래서 브라우저가 직접 가져옵니다.

| | 어디서 | 막힐 일 |
|---|---|---|
| 코인 | 업비트 | 거의 없음 |
| 환율 | er-api → frankfurter → 두나무 → 네이버 → 야후 | 거의 없음 |
| **국내주식·ETF** | 📗 구글시트 → **네이버 금융** → 야후 | 📜 구글 스크립트를 연결하면 거의 없음 |
| 미국주식·ETF | 📗 구글시트 → **야후** → 네이버 해외주식 | 📜 구글 스크립트를 연결하면 거의 없음 |
| 금 | 국제 금시세(야후) → 네이버 | 가끔 있음 |

**국내주식은 네이버 금융**을 봅니다 — 증권사 앱에 뜨는 값과 같습니다.
브라우저가 이 서버들을 바로 부르지 못해서 **공개 중계 서버**를 순서대로 시도하고,
한 번 성공한 경로를 기억해서 다음부터는 그것부터 씁니다.

한 경로가 막히면 그 경로만 접고 다음으로 넘어가며, 전부 막히면 **바로 포기**하고 알려줍니다
(예전에는 종목마다 전부 다시 헤매느라 몇 분씩 «불러오는 중»에서 멈춘 것처럼 보였습니다).

**다 막히면** 마지막으로 받아 둔 시세를 그대로 보여주고 위쪽에 몇 건 실패했는지 알려줍니다.
그럴 땐 종목을 눌러 **시세 직접 입력**에 값을 적으면 됩니다 — 적어 둔 값이 자동 조회보다 우선합니다.

시세는 **종목 하나에 하나**입니다. 같은 종목을 계좌 여러 곳에 갖고 있어도
직접 적은 값은 **모든 계좌에 함께** 적용됩니다. (묶음 화면의 **🔧 시세 고치기** 로 한 번에)

> ⚠️ 가져온 시세가 내 **평균 매수가와 5배 넘게** 차이 나면 `⚠️ 시세 확인` 표시가 붙습니다.
> 시세 서버가 엉뚱한 값을 준 경우일 수 있으니 증권사 앱과 비교해 보고 다르면 직접 적어 주세요.

시세는 **앱을 열 때 한 번**, 그리고 보고 있는 동안 정해 둔 주기마다 가져옵니다.
⚙️ → **얼마나 자주 새로 가져올까요** 에서 `열 때만 / 2분 / 10분 / 30분 / 1시간` 중에 고르세요 (기본 10분).
🔄 를 누르면 언제든 바로 갱신됩니다.

> 국내장은 평일 9시~15시 30분에만 값이 바뀝니다. 장이 닫혀 있으면 자주 가져와도 같은 값이에요.

### 📜 구글 스크립트로 시세 받기 — 한 번만 설정 (추천)

무료 공개 중계 서버들은 자주 막힙니다. 실제로 **7곳이 전부 죽어서** 네이버·야후를
아예 못 부르는 일이 있었습니다.

**내 구글 계정 안에 중계를 하나 만들어 두는 방법**입니다.
구글 서버가 대신 네이버·야후를 불러 주므로 브라우저의 CORS 제약을 받지 않습니다.

**5분이면 되고, 그 뒤로는 종목을 아무리 추가해도 다시 손댈 게 없습니다.**

⚙️ → **📜 구글 스크립트로 시세 받기**

1. [script.new](https://script.new) 를 엽니다
2. 안에 있던 코드를 **전부 지우고** 앱에서 **📋 코드 복사**한 것을 붙여넣기
3. 오른쪽 위 **배포** → **새 배포** → 톱니바퀴에서 유형 **웹 앱**
4. 액세스 권한을 **모든 사용자** 로 → **배포**
5. 권한 화면에서 **고급(Advanced)** → **…(으)로 이동 / Go to …(unsafe)** → **허용(Allow)**
6. 나온 **웹 앱 URL**(`…/exec`)을 앱에 붙여넣고 **연결하기**

> ⚠️ 5번에서 뜨는 **「Google hasn't verified this app」** 경고는 **정상**입니다.
> 내가 방금 만든 스크립트라 구글이 심사한 적이 없어서 그렇습니다 —
> 경고문에 개발자가 **내 이메일**로 적혀 있는 걸 확인할 수 있어요.
> **고급 → 이동 → 허용** 으로 통과하세요. `BACK TO SAFETY` 를 누르면 취소됩니다.

붙여넣는 코드는 이게 전부입니다.

```js
    muteHttpExceptions: true,
    followRedirects: true,
    headers: { 'User-Agent': 'Mozilla/5.0', 'Referer': 'https://finance.naver.com/' }
  });
  return ContentService.createTextOutput(r.getContentText())
    .setMimeType(ContentService.MimeType.JSON);
}
```

내 구글 계정 안에서만 도는 중계라 남이 쓸 수 없고, 시세 주소만 받아옵니다.

### 📗 구글시트로 시세 받기 — 다른 방법

무료 공개 중계 서버들은 자주 막힙니다. 실제로 **7곳이 전부 죽어서** 네이버·야후를
아예 못 부르는 일이 있었습니다. 그럴 때 쓰는 길입니다.

구글은 브라우저가 **바로 부를 수 있어서**(중계 필요 없음) 이 방법이 제일 안정적이고,
`GOOGLEFINANCE` 는 KRX 시세를 정확히 줍니다.

⚙️ → **📗 구글시트로 시세 받기**

1. **📋 수식 복사** — 담아 둔 종목으로 수식을 자동으로 만들어 줍니다
2. [sheets.new](https://sheets.new) 로 새 시트를 만들고 **A1**에 붙여넣기
3. 파일 → 공유 → **웹에 게시** → 형식을 **쉼표로 구분된 값(.csv)** → 게시
4. 나온 주소를 앱에 붙여넣고 **연결하기**

붙여넣는 수식은 이렇게 생겼습니다 (**줄바꿈 없는 한 줄**입니다).

```
={"code","price","prev";"kr:000660",IFERROR(GOOGLEFINANCE("KRX:000660","price"),""),IFERROR(GOOGLEFINANCE("KRX:000660","closeyest"),"");"fx:USD",IFERROR(GOOGLEFINANCE("CURRENCY:USDKRW"),""),""}
```

> ⚠️ **A1 한 칸**에 통째로 들어가야 합니다.
> A1에 `#ERROR!` 가 뜨고 A2·A3에 글자가 흩어져 있으면 잘못 들어간 것이니,
> A1부터 아래까지 다 지우고 다시 붙여넣어 주세요.

시트를 연결하면 **주식과 환율을 여기서 먼저** 받고, 시트에 없는 것만 네이버·야후로 갑니다.
코인은 그대로 업비트에서 받습니다.

> ⚠️ **종목을 새로 담을 때마다** 수식을 다시 복사해서 시트 A1에 붙여넣어야 합니다.
> 앱이 «시트에 없는 종목이 N개 있어요» 라고 알려주긴 하지만, 이게 번거로우면
> 위의 **📜 구글 스크립트** 쪽을 쓰세요 — 그쪽은 한 번 만들면 다시 손댈 게 없습니다.

### 🛠 내 중계 서버 (아는 분만)

직접 만든 중계 서버(예: Cloudflare Worker)가 있으면 ⚙️ → **🛠 내 중계 서버** 에 주소를 넣으세요.
`{url}` 자리에 실제 주소가 들어가고, 이 경로를 가장 먼저 씁니다.

### 🩺 시세가 안 붙을 때

⚙️ → **🩺 시세 점검** (또는 화면 위 시세 글씨를 누르면) 어디서 막혔는지 하나씩 짚어 줍니다.

- **중계 경로** 7곳 중 어디로 닿는지
- **시세 출처**(네이버·야후·업비트·두나무)가 각각 값을 주는지

**📋 결과 복사하기** 로 복사해서 보내 주시면 원인을 바로 알 수 있습니다.

> 🥇 금은 **국제 시세(달러/트로이온스)를 원/g으로 환산**한 값입니다.
> 한국금거래소 소매가와는 차이가 있으니, 그 값으로 보고 싶으면 직접 입력해 주세요.

## 🧾 가계부 앱과 연동

가계부 앱 **💎 자산** 탭에서 이 앱의 금액을 그대로 불러올 수 있습니다.

- 두 앱을 **같은 폰**에서 쓰면 아무 설정 없이 바로 읽힙니다.
- 다른 폰이라면 두 앱 모두 **같은 Firebase 방**에 연결하면 됩니다.

가계부 자산 탭에 뜨는 `📊 자산 앱` 카드에서 **반영** 을 누르면
그 달 평가액 칸이 자산 앱 금액으로 채워집니다. (누르기 전엔 아무것도 바뀌지 않습니다.)

| 자산 앱 | → | 가계부 자산 항목 |
|---|---|---|
| 국내주식·미국주식 | → | 주식·펀드 |
| 코인 | → | 코인 |
| 부동산 | → | 아파트 / 토지 |
| 예적금·현금 | → | 예적금 / CMA |
| 연금·펀드·기타 | → | 연금펀드/ISA |
| 금·달러 | → | 기타 |

이름으로 자동으로 짝을 맞추고, 마음에 안 들면 직접 고를 수 있습니다.

## 만든 사람을 위한 메모

- 자산 한 줄: `{ id, cat, code, sym, name, owner, acct, kind, qty, avg, avgFx, loan, mp, mpAt,
  memo, target, stop, why, notes[] }`
- `kind` 는 성격(`stock` `bond` `gold` `fx` `real` `cash` `coin` `etc`). 비어 있으면 이름으로 짐작(`guessKind`).
- 계좌 종류는 `state.accts = { '<계좌이름>': { type } }` 에 따로 둡니다 — 자산에는 이름만 들어갑니다.
- 일기: `state.diary = [{ id, at, date, text, hold, net, tot }]`
- `acct` 는 계좌·증권사 이름. 같은 `code` 라도 `owner`+`acct` 가 다르면 다른 줄입니다.
  화면에서는 `cat:code` 로 묶어서 합계를 보여줍니다(`groupOf` · `calcGroup`).
- `cat`: `kr` `us` `coin` `gold` `fx` `real` `cash` `etc`
- `mp` 는 직접 입력한 시세. 있으면 자동 조회를 이깁니다.
- 저장 키: `myAssets.v1` · Firestore 경로: `rooms/{room}/assets/core`
  (가계부가 이 경로를 읽습니다. 바꾸면 연동이 끊깁니다.)
- 공유되는 값: `settings` `holdings` `accts` `diary` `memo` `led` — 시세 캐시와 추이 기록은 폰마다 따로입니다.
