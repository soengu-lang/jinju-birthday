# 우리집 가계부 💰

구글 스프레드시트로 쓰던 가계부를, **폰에서 한 손으로** 쓰는 앱으로 옮겼습니다.
시트에 적어 둔 내용은 **복사해서 붙여넣기 한 번**으로 그대로 가져옵니다.

앱 파일은 `index.html` **하나**뿐입니다. 서버도, 설치도, 회원가입도 없습니다.

## 어떻게 여나요

| 방법 | 하는 법 |
|---|---|
| 폰에서 쓰기 (추천) | `https://soengu-lang.github.io/jinju-birthday/household-budget/` 접속 → 브라우저 메뉴에서 **홈 화면에 추가** |
| PC에서 바로 | `index.html` 파일을 더블클릭 |

> 💡 **홈 화면에 추가**를 해 두면 주소창 없이 전체화면으로 뜨고 아이콘도 생겨서, 마트 계산대 앞에서 두 번 눌러 기록할 수 있습니다.

## 📥 구글 시트 내용 옮기기 (제일 먼저 할 일)

⚙️ → **📥 구글 시트에서 가져오기**

**폰에서**
1. 구글 시트 앱에서 표를 **길게 눌러 전체 선택 → 복사**
2. 앱의 붙여넣기 칸을 꾹 눌러 **붙여넣기** → `다음(미리보기)`

**PC에서**
1. 시트에서 범위를 드래그 → `Ctrl+C`
2. 앱의 칸에 `Ctrl+V` → `다음(미리보기)`
   (또는 시트에서 **파일 → 다운로드 → CSV**로 받아 `📄 CSV 파일` 버튼으로 골라도 됩니다)

### 칸은 알아서 맞춰 줍니다
머리글(날짜·분류·내용·금액·결제수단…)을 읽어 **어느 칸이 무엇인지 자동으로 추측**하고,
미리보기로 *"이렇게 들어갑니다"* 를 먼저 보여 줍니다. 틀린 것만 드롭다운으로 바꾸면 됩니다.

| 이런 것도 알아서 읽습니다 | 예시 |
|---|---|
| 날짜 여러 형태 | `2026-08-23`, `2026. 8. 23`, `2026년 8월 23일`, `8/23`, 엑셀 날짜 숫자 |
| 금액 여러 형태 | `12,000`, `₩12000`, `12000원`, `3만원`, `(3,000)`(마이너스) |
| 지출·수입 칸이 나뉜 시트 | `지출` 칸과 `수입` 칸을 따로 지정 |
| 금액이 마이너스면 수입 | 체크박스로 켜고 끄기 |
| 시트의 분류 이름 | `마트` → `마트·장보기`, `교통` → `교통·차량` 처럼 **비슷한 이름끼리 자동으로 연결**하고, 없는 이름은 새 분류로 추가 |
| 분류 칸이 아예 없을 때 | 내용(`스타벅스`, `이마트`, `지하철`…)을 보고 분류를 추측 |

**여러 번 가져와도 안전합니다.** `이미 있는 기록은 건너뛰기`가 켜져 있어,
같은 시트를 또 붙여넣어도 중복으로 쌓이지 않습니다(날짜·금액·내용이 같으면 건너뜁니다).

### 다시 시트로 보내기
⚙️ → **📤 내보내기** → 복사한 뒤 구글 시트 첫 칸에 붙여넣으면 표로 들어갑니다(CSV).
CSV 파일로 내려받을 수도 있어요.

## 다섯 개의 탭

### 🏠 홈 — 여기서 대부분 끝납니다
- 이번 달 쓴 돈, 예산 대비 몇 %, **남은 날 동안 하루에 얼마 쓸 수 있는지**,
  지난달 같은 기간 대비, 이 속도면 월말에 얼마가 될지를 맨 위에서 보여 줍니다.
- **빠른 입력**: 금액 → 분류 칩 → `오늘 기록하기`. 세 번만 누르면 끝입니다.
  - `+1천 +5천 +1만 +5만` 버튼으로 금액을 눌러서 채울 수도 있어요.
  - 분류를 안 골라도 내용(`스타벅스`, `이마트`…)을 보고 알아서 분류합니다.
- **자주 쓰는 항목**: 두 번 이상 적은 내용은 칩으로 올라옵니다. 누르면 금액·분류가 그대로 채워져요.
- 이번 달에 아직 기록하지 않은 **고정지출**이 있으면 `기록` 버튼과 함께 알려 줍니다.

### 📒 내역 — 날짜별로 모아 보기
- 달을 ‹ › 로 넘기며 봅니다. 지출·수입·남은 돈 합계가 위에 나옵니다.
- 분류 칩으로 거르고, 내용·분류·결제수단으로 **검색**할 수 있어요.
- 기록을 누르면 수정·삭제 창이 열립니다.

### 📅 달력 — 어느 날 많이 썼나
- 날짜 칸에 그 날 지출이 표시되고, **많이 쓴 날일수록 색이 진해집니다.**
- 한 푼도 안 쓴 날은 ☺️ 로 표시되고, 아래에 **무지출 며칠**인지 세어 줍니다.
- 날짜를 누르면 그 날 기록이 아래에 펼쳐지고, 그 날짜로 바로 기록을 추가할 수 있어요.

### 📊 분석 — 어디에 새는지
- 분류별 비중을 도넛과 막대로 보여 주고, **지난달과 비교**해 ▲▼ 로 알려 줍니다.
- 주차별 지출, 결제수단별 지출, **큰 지출 TOP 5**.
- 예산을 넘긴 분류는 위에 경고로 뜹니다.

### 💰 예산 — 넘기 전에 알기
- **한 달 총예산**과 **분류별 예산**을 정하면 사용률 막대가 채워집니다(숫자만 고치면 바로 저장).
- **고정지출**(월세·통신비·구독료)을 등록해 두면 매달 `기록` 버튼 한 번으로 들어가고,
  `한 번에 기록` 으로 남은 것들을 모두 처리할 수도 있어요.
- 이번 달 수입과 저축(수입−지출)이 아래에 정리됩니다.

## 👨‍👩‍👧 가족과 함께 쓰기 (선택)

기본은 폰 한 대에만 저장되지만, **Firebase**를 연결하면 두 폰이 같은 가계부를 봅니다.
남편이 마트에서 기록하면 아내 폰에서도 바로 보이는 식이에요.

**한 사람만** 아래 준비를 하면 되고, 나머지 식구는 **초대 링크만 열면** 끝입니다.

### 준비 (한 번만, 약 5분 · 무료)
1. [console.firebase.google.com](https://console.firebase.google.com) 접속 → 구글 로그인
2. **프로젝트 만들기** → 이름 아무거나 (애널리틱스는 꺼도 됩니다)
3. 왼쪽 **빌드 → Firestore Database** → **데이터베이스 만들기** → 위치는 기본값
4. **규칙** 탭을 아래 내용으로 바꾸고 **게시**

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /rooms/{roomId}/{document=**} {
      allow read, write: if roomId.size() >= 16;
    }
  }
}
```

5. ⚙️ **프로젝트 설정** → 아래로 내려 **웹앱(`</>`)** 추가 → 나오는 `firebaseConfig` 값을 통째로 복사
6. 앱에서 ⚙️ → **가족과 함께 쓰기 시작하기** → 복사한 값 붙여넣기 → **연결하고 방 만들기**
7. 나오는 **초대 링크를 배우자에게 카톡으로** 전송 → 상대는 링크를 열고 **참여**만 누르면 끝

> 홈 화면에 추가한 앱처럼 **주소창이 없어 링크를 열 수 없는 곳**에서는,
> ⚙️ → **🔗 초대 링크로 참여하기** 에 링크를 붙여넣으면 똑같이 참여됩니다.

### 어떻게 동작하나요
- 전체 데이터가 `rooms/{방}/state/core` 문서 하나에 저장됩니다.
- 화면을 보고 있을 때만 **15초마다 문서 1건**을 확인하고, 바뀌었을 때만 내려받습니다.
  가족 두세 명이 쓰는 정도는 무료 한도 안에 넉넉히 들어옵니다.
- **동시에 같은 걸 고치면 나중에 저장한 쪽이 이깁니다.**
- **인터넷이 끊긴 곳(마트 지하 등)에서 적은 내용은 폰에 남아 있다가 연결되면 올라갑니다.**
  아직 못 올린 내 변경이 있으면 남의 내용을 먼저 받아 덮어쓰지 않도록 막아 뒀어요.
- **초대 링크를 아는 사람은 우리 방에 들어올 수 있습니다.** 가족에게만 보내세요.
- 공유가 꺼져 있으면 **네트워크 요청을 한 건도 보내지 않습니다.**

## 데이터는 어디에 저장되나요

- 모든 기록은 **그 브라우저 안(localStorage)** 에만 저장됩니다. 가족 공유를 켜지 않으면 서버로 아무것도 보내지 않고, 인터넷이 끊겨도 돌아갑니다.
- 대신 **폰을 바꾸거나 브라우저 데이터를 지우면 사라집니다.** ⚙️에서 가끔
  **⬇️ 백업 파일 내려받기**를 해 두고, 새 기기에서 **⬆️ 불러오기** 하세요.

### ⚠️ 브라우저가 다르면 기록도 따로입니다
카카오톡 내장 브라우저, 사파리, 크롬, 홈 화면에 추가한 앱은 **각각 다른 저장소**를 씁니다.
옮기려면 ⚙️ → **📋 백업 내용 복사** → 옮길 브라우저에서 **📥 붙여넣어 복원하기**.
**가족 공유(Firebase)를 켜 두면** 기기가 달라도 같은 방을 보므로 이 문제가 아예 없어집니다.
