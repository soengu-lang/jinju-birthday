# 우리집 가계부 💰

구글 스프레드시트로 쓰던 **부부 자산 관리 시트**를 폰에서 한 손으로 쓰도록 옮긴 앱입니다.
시트의 구조(행=항목 · 열=월)를 그대로 두고, 입력만 훨씬 쉽게 만들었습니다.

앱 파일은 `index.html` **하나**뿐입니다. 서버도, 설치도, 회원가입도 없습니다.

## 어떻게 여나요

| 방법 | 하는 법 |
|---|---|
| 폰에서 쓰기 (추천) | `https://soengu-lang.github.io/jinju-birthday/household-budget/` 접속 → 브라우저 메뉴에서 **홈 화면에 추가** |
| PC에서 바로 | `index.html` 파일을 더블클릭 |

> 💡 **홈 화면에 추가**를 해 두면 주소창 없이 전체화면으로 뜨고 아이콘도 생깁니다.

## 📦 시트에서 이미 옮겨져 있는 것

첫 화면부터 **시트에 적혀 있던 내용이 그대로 들어 있습니다.**

| 시트 | 옮겨진 내용 |
|---|---|
| 🧾 가계부 | 수입·고정비·저축·생활비 **37개 항목**, 1~6월 입력값 전부 |
| 💎 자산 | 진주·성우 자산과 부채 **22개 항목**, 초기(2025.12)~2026.6 |
| 🔁 고정비 | 점검표 **33건** (금액·누구·결제일·상태·메모·절감 가능액) |
| 💳 대출 | 미래에셋·카카오·신한 **3건** (금리·월 상환액·우선순위) |
| 🎯 목표 | 목표 15억 · 연 5% · 월 저축 300만 |
| 💪 절약 | 습관 카드 **11개**와 이번 달 실행 횟수 |
| 메모 | 그대로 |

숫자도 시트와 같습니다 — 예: 5월 수입 9,324,620원 / 지출 2,924,103원 / 순저축 6,400,517원,
고정비 월 2,559,877원, 줄일 수 있는 돈 156,571원.

> ⚙️ → **↩️ 시트 원본 데이터로 되돌리기** 를 누르면 언제든 이 처음 상태로 돌아갑니다.

## 다섯 개의 탭

### 🏠 홈 — 한눈에
- **현재 순자산**, 목표까지 몇 %, 지난달 대비 얼마 늘었는지
- 이번 달 **순저축 · 저축률 · 절약액**
- 그 달 가계부 요약(수입/고정비/저축/생활비)
- **빠른 기록**: 금액 → 항목 칩 → 버튼 한 번이면 그 달 생활비에 더해집니다
- 자산 구성 도넛, 순자산 추이 그래프, 고정비 요약, 메모

### 🧾 가계부 — 시트의 그 표
- ‹ › 로 달을 넘기며 봅니다. 위에 **수입 / 지출 / 저축 / 순저축 + 저축률**.
- 항목을 누르면 그 달 금액을 고칠 수 있어요. `+1만 +5만 …` 버튼도 있습니다.
- **상세 기록**: 한 항목에 "이마트 12,000" 처럼 여러 건을 더할 수 있고,
  그 달 합계는 `직접 적은 금액 + 상세 기록` 으로 자동 계산됩니다.
- **지난달 값 채우기**: 월세·보험처럼 매달 같은 금액은 버튼 한 번으로 채워집니다(빈 칸만).
- **📅 1년 전체 보기**를 누르면 시트와 똑같은 12개월 표가 나옵니다(옆으로 스크롤).

### 💎 자산 — 매월 말 평가액
- 초기(2025.12)부터 12월까지 달을 넘기며 **진주 / 성우 / 부채**를 입력합니다.
- 그 달에 안 적은 항목은 **가장 최근 값이 이어져** 계산됩니다(`5월 값 이어짐` 표시).
  같은 금액이면 **지난달 값 그대로** 버튼 한 번이면 끝나요.
- 자산 구성 도넛·막대, 순자산 추이, **1년 전체 표**.

### 🔁 고정비 — 새는 돈 찾기
- 매달 나가는 돈 합계, 연 환산, **줄일 수 있는 돈**을 위에서 보여 줍니다.
- 분류(주거·통신·보험·이자·구독·청약·차량)별로 묶여 있고,
  `🚨 점검` 배지가 붙은 항목만 모아 볼 수 있어요.
- 아래에 **💳 대출**(잔액·금리·월 상환액·우선순위)이 함께 있습니다.

### 🎯 목표 — 언제 달성하나
- 목표 순자산·기대수익률·월 저축액을 넣으면 **몇 년 몇 개월 뒤 달성**인지, 예상 시점,
  **10년 시뮬레이션**을 보여 줍니다(시트와 같은 계산식).
- 아래 **💪 절약 습관**은 `＋`를 누를 때마다 절약액이 쌓이고, 이번 달 누적과 연 환산이 나옵니다.

## 🔄 시트와 계속 주고받기

- ⚙️ → **📥 시트에서 가져오기**: 구글 시트에서 표를 머리글(월 이름)까지 복사해 붙여넣으면
  같은 이름의 항목을 찾아 그 달 칸을 채웁니다. 없는 이름은 새 항목으로 추가돼요.
  가계부 표·자산 표 둘 다 되고, CSV 파일도 됩니다.
- ⚙️ → **📤 시트로 내보내기**: 1년 표를 복사해 시트 첫 칸에 붙여넣으면 그대로 표가 됩니다.

## 📋 카드·계좌 내역 붙여넣기 — 자동으로 항목에 넣기

은행 앱 거래내역이나 카드 결제 문자를 **통째로 붙여넣으면** 날짜·내용·금액을 읽어
항목별 상세 기록으로 넣어 줍니다. 가계부 탭의 **📋 카드·계좌 내역 붙여넣기** (⚙️에도 있음).

**이런 형태를 읽습니다**

| 형태 | 예 |
|---|---|
| 은행 앱 목록 | `8월 27일` / `스타벅스  -5,600` / `급여  +3,200,000` |
| 은행 앱 상세형 | `2026.08.25` / `출금 250,000원` / `관리비` / `잔액 …` |
| 카드 결제 문자 | `[Web발신] 신한카드(1234) 승인 … 12,000원 일시불 08/27 스타벅스` (여러 통 한꺼번에) |
| 엑셀·CSV | `거래일자,적요,출금액,입금액,잔액` 표 |

- 가맹점 이름을 보고 **항목을 자동으로 골라 줍니다** (스타벅스→외식, 이마트→마트, 주유→교통비…)
- 미리보기에서 항목을 한 번 고쳐 주면 **그 가게는 다음부터 자동**으로 들어갑니다
- **카드대금 결제는 자동으로 제외**합니다(항목에 이미 있어서 두 번 세니까요)
- 같은 내역을 또 붙여넣어도 **이미 있음**으로 표시되어 중복으로 쌓이지 않습니다
- 잔액·누적·승인번호·카드번호·이름(홍*동)은 알아서 걸러냅니다

**📄 파일로 불러오기** — 카드사·은행에서 받은 파일을 붙여넣기 없이 바로 열 수 있습니다
- `📄 파일 열기` → CSV·TXT·엑셀(.xls/.xlsx) 선택
- 한글이 깨지는 **EUC-KR(CP949)** 파일도 자동으로 알아봅니다
- 표의 머리글(`거래일시 / 적요 / 출금액 / 입금액 / 잔액`)을 읽어 **입금·출금을 구분**하고, 잔액 칸은 금액으로 세지 않습니다
- 엑셀 파일은 표를 읽는 도구를 그때 한 번 내려받아서 **인터넷 연결이 필요**합니다(CSV는 필요 없음).
  안 되면 엑셀에서 열어 복사 → 붙여넣기 하셔도 결과는 같습니다

## 💳 카드·계좌 대조 — 빠진 소비 찾기

카드값을 통째로 적으면 고정비·장보기와 **중복**되고, 항목만 적으면 자잘한 소비가 **누락**됩니다.
그래서 이 앱은 **적는 건 용도 기준(식비·마트·의료…)** 으로 두고, 카드 명세서는 **맞는지 확인하는 자(尺)** 로만 씁니다.

**한 번만 준비**
- 가계부 탭 맨 아래 `💳 카드·계좌 대조` → **항목별 결제수단 지정**
- 묶음별로 한 번에 정할 수 있어요 (고정비 전체 → 계좌이체, 생활비 전체 → 카드)
- **결제수단 편집**에서 이름을 실제 카드로 바꾸고(신한카드·삼성카드…) 필요한 만큼 추가

**매달 하는 일**
1. 카드 명세서 금액만 입력
2. 앱이 `적어 둔 합계 730,534 / 명세서 900,000 → 안 적힌 소비 169,466원` 을 보여줍니다
3. **「＋169,466원을 기타 생활비에 넣기」** 를 누르면 총액이 딱 맞습니다
   - 명세서 금액을 고치고 다시 눌러도 **중복으로 쌓이지 않고** 새 금액에 맞춰 조정됩니다

> ⚠️ 계좌·현금은 **카드대금 이체를 뺀 금액**으로 넣으세요. 카드로 쓴 건 이미 항목에 적혀 있어서 두 번 세게 됩니다.

## 📅 세금·연회비 — 1년에 한두 번 나가는 돈

재산세·자동차세처럼 **매달이 아니라 1년에 한두 번** 나가는 돈은 고정비와 따로 관리합니다.
고정비 탭 맨 아래 `📅 세금·연회비`.

**넣는 법**
- **🇰🇷 우리나라 세금 일정에서 고르기** → 해당되는 것만 `＋`, 또는 **한 번에 다 넣기** 후 필요 없는 건 삭제
- 금액은 나중에 고지서 보고 채워도 됩니다(모르면 비워 두세요)
- 직접 추가할 때는 이름·금액·**내는 달(여러 개 선택)**·넣을 항목만 정하면 됩니다

**넣어 둔 일정** (일반적인 납부 시기입니다 — 대상 여부와 금액은 **위택스·홈택스 고지서** 기준)

| 항목 | 내는 달 |
|---|---|
| 재산세 (주택) | 7월·9월 반씩 |
| 재산세 (토지) / 재산세 (건축물) | 9월 / 7월 |
| 종합부동산세 | 12월 (공제 넘을 때만) |
| 자동차세 | 6월·12월 (1월 연납 시 할인) |
| 주민세 (개인분) | 8월 |
| 종합소득세·지방소득세 | 5월 |
| 건강보험료 정산 | 4월 |
| 연말정산 (추가납부·환급) | 2월 |
| 자동차 보험 갱신 | 갱신 달로 바꿔 쓰기 |
| 등록면허세 | 1월 |

**그 달이 오면**
- 🏠 홈에 **🔔 알림 카드**가 뜹니다 — `재산세 (주택) · 9월에 낼 차례 · 340,000원` + **기록** 버튼
- **기록**을 누르면 그 달 가계부의 `세금·공과금` 항목(없으면 자동 생성)에 들어가고, 그 해 그 달은 **완료**로 표시됩니다
- 다음 달에 낼 것도 미리 한 줄로 알려줍니다
- 1년 합계와 월 평균이 목록 아래에 나와서, 매달 얼마씩 모아 둬야 하는지 볼 수 있습니다

## 🧊 냉장고 식단표 앱과 자동 연동

같은 저장소의 [냉장고 식단표](../fridge-meal-planner/) 앱에 적은 **식비가 이 가계부에 자동으로 들어옵니다.**
따로 누를 필요가 없고, 냉장고 앱에서 금액을 고치면 여기도 따라 바뀝니다.

| 냉장고 앱 식비 | 가계부 생활비 |
|---|---|
| 🛒 장보기 | 마트(식품) |
| 🍽️ 외식 + ☕ 카페·간식 | 외식(식당, 카페) |
| 🛵 배달 | 배달 |

- 가계부 항목 줄에 `🧊 냉장고에서 74,700원` 처럼 표시되고,
  그 달 합계는 `직접 적은 금액 + 상세 기록 + 냉장고 금액` 입니다.
- **같은 폰·같은 브라우저**에서 두 앱을 쓰면 설정 없이 처음 열 때부터 켜집니다.
- 냉장고 앱을 **다른 폰·다른 브라우저**에서 쓴다면, 냉장고 앱의 가족 공유를 켠 뒤
  ⚙️ → 냉장고 식단표 연동 → **🔗 냉장고 초대 링크로 연결** 에 붙여넣으세요.
  가계부는 냉장고 방을 **읽기만** 하고 아무것도 쓰지 않습니다.
- ⚙️ → 연동 설정에서 **어느 항목에 넣을지 바꾸기 / 끄기 / 지금 다시 읽기** 가 됩니다.
- 이 계산은 **폰마다 따로** 이뤄집니다(배우자 폰에서도 보이게 하려면 그 폰에서도 켜 주세요).

## 📊 자산 앱과 연동 — 💎 자산 칸 자동으로 채우기

같은 저장소의 [우리집 자산](../my-assets/) 앱에 담아 둔 **주식·코인·달러·금·부동산** 금액을
💎 자산 탭으로 그대로 가져올 수 있습니다.

💎 자산 탭 맨 위의 `📊 자산 앱 연동` 카드에서 연결합니다. 두 가지 길이 있어요.

| 어떤 상황 | 어떻게 |
|---|---|
| 같은 사파리 창에서 두 앱을 쓴다 | `이 브라우저에서 읽기` — 설정 없이 바로 |
| **둘 다 홈 화면 앱**이다 (Firebase 없음) | `📋 붙여넣어 가져오기` — **가장 쉬운 길** |
| Firebase 공유를 켜 두었다 / 다른 폰이다 | `🔗 초대 링크로 연결` — 그 뒤로는 저절로 |

> 📱 **홈 화면에 추가한 앱끼리는 저장 공간이 서로 다릅니다.**
> 그래서 홈 화면 가계부 앱은 홈 화면 자산 앱의 기록을 볼 수 없어요.

**① 붙여넣기 (Firebase 없이)**
자산 앱 ⚙️ → **🧾 가계부 앱과 연동** → **📋 가계부에 붙여넣을 요약 복사** →
가계부 💎 자산 탭 → **📋 붙여넣어 가져오기** 에 붙여넣기.
금액이 바뀌면 다시 복사·붙여넣기 하면 됩니다.

**② 초대 링크 (한 번 연결하면 끝)**
자산 앱에서 **💑 배우자와 함께 보기**를 켠 뒤 ⚙️ → **🔗 초대 링크 복사** →
가계부의 **🔗 초대 링크로 연결** 에 붙여넣기. 그 뒤로는 저절로 따라옵니다.
(가계부 ⚙️ → **📊 자산 앱 연동** 에서도 두 버튼을 다 누를 수 있습니다.)

| 자산 앱 | → | 가계부 자산 항목 |
|---|---|---|
| 국내주식 · 미국주식 | → | 주식·펀드 |
| 코인 | → | 코인 |
| 부동산 | → | 아파트 / 토지 |
| 예적금·현금 | → | 예적금 / CMA |

## 👨‍👩‍👧 부부가 함께 쓰기 (선택)

기본은 폰 한 대에만 저장되지만, **Firebase**를 연결하면 두 폰이 같은 가계부·자산을 봅니다.
**한 사람만** 준비(무료, 약 5분)하면 되고, 배우자는 **초대 링크만 열면** 끝입니다.

> 🧊 **냉장고 식단표 앱을 이미 Firebase로 공유 중이라면**, 같은 브라우저에서 가계부 ⚙️ →
> **함께 쓰기 시작하기** 를 열면 맨 위에 **「냉장고 앱에 쓰던 Firebase 그대로 쓰기」** 버튼이 뜹니다.
> 아래 준비 없이 눌러서 바로 연결되고, 가계부 전용 방이 새로 만들어집니다(냉장고 기록과 섞이지 않아요).

1. [console.firebase.google.com](https://console.firebase.google.com) → 구글 로그인 → **프로젝트 만들기**
2. **빌드 → Firestore Database → 데이터베이스 만들기**
3. **규칙** 탭을 아래로 바꾸고 **게시**

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /rooms/{roomId}/{document=**} {
      allow read, write: if roomId.size() >= 16;
    }
  }
}
```

4. ⚙️ **프로젝트 설정 → 웹앱(`</>`) 추가** → 나오는 설정값 복사
5. 앱 ⚙️ → **함께 쓰기 시작하기** → 붙여넣기 → **연결하고 방 만들기**
6. **초대 링크**를 배우자에게 보내면, 열고 **참여**만 누르면 됩니다

- 화면을 보고 있을 때만 15초에 한 번 확인하므로 무료 한도 안에서 넉넉히 돌아갑니다.
- 동시에 같은 칸을 고치면 나중에 저장한 쪽이 남습니다.
- 인터넷이 끊긴 곳에서 적은 내용은 폰에 있다가 연결되면 올라갑니다.
- 초대 링크를 아는 사람은 방에 들어올 수 있으니 **가족에게만** 보내세요.

## 데이터는 어디에 저장되나요

- 모든 기록은 **그 브라우저 안(localStorage)** 에만 저장됩니다. 공유를 켜지 않으면 서버로 아무것도 보내지 않아요.
- **폰을 바꾸거나 브라우저 기록을 지우면 사라집니다.** ⚙️에서 가끔 **⬇️ 백업 파일 내려받기**,
  다른 브라우저로 옮길 땐 **📋 백업 내용 복사 → 📥 붙여넣어 복원하기**.
- 카톡 내장 브라우저·사파리·크롬·홈 화면 앱은 저장소가 서로 다릅니다(공유를 켜면 이 문제가 없어져요).
