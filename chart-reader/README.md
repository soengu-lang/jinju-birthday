# 차트 지표 읽기 📈

주식 차트를 **캡처해서 넣기만 하면**, 그 화면에 그려진 보조지표가 지금 어떤 모양인지
**그대로 읽어서 말로 설명해 주는 앱**입니다.

**색을 하나하나 찍어 줄 필요가 없습니다.** 사진을 넣으면 앱이 알아서
캔들 영역을 찾아 자르고, 어떤 색이 무슨 지표인지 가려내고, 몇 일선인지까지 맞춰서
곧바로 결과를 보여 줍니다. 틀린 것만 손으로 고치면 됩니다.

- 이동평균선 · 볼린저밴드 · 일목균형표 · 캔들
- 방향, 선 순서(정배열·역배열), 교차(골든/데드크로스), 밴드 폭, 구름 위·아래…
- **사고팔라는 이야기는 하지 않습니다.** 지표가 어떤 상태이고 그 상태를 뭐라고 부르는지까지만 적습니다.

앱 파일은 `index.html` **하나**뿐입니다. 서버도, 설치도, 회원가입도 없고,
**넣은 사진은 폰 밖으로 나가지 않습니다**(브라우저 안에서만 처리).

## 어떻게 여나요

| 방법 | 하는 법 |
|---|---|
| 폰에서 쓰기 (추천) | `https://soengu-lang.github.io/jinju-birthday/chart-reader/` 접속 → 브라우저 메뉴에서 **홈 화면에 추가** |
| PC에서 바로 | `index.html` 파일을 더블클릭 |

---

## 쓰는 순서

**사진 넣기 → 끝.** 1초 남짓이면 결과가 나옵니다.
넣는 방법은 사진 고르기 · 끌어다 놓기 · 붙여넣기(Ctrl+V) 모두 됩니다.

읽고 나면 **사진에서 읽은 것** 칸에 무엇을 찾았는지 색과 함께 보여 줍니다.
틀렸거나 빠진 게 있을 때만 **손으로 고치기**를 누르세요.

| 손으로 할 수 있는 것 | 하는 법 |
|---|---|
| 영역 다시 자르기 | **① 영역 자르기**에서 캔들 칸만 드래그 |
| 색 다시 찍기 | **② 색 찍기**에서 선 위를 꾹 누르면 **확대경**이 뜹니다 |
| 기간 고치기 | 이평선 줄의 숫자 칸에 5·20·60 처럼 적습니다 |
| 가격 눈금 *(선택)* | 값을 아는 높이 두 곳을 찍고 숫자를 적으면 결과에 **% 와 실제 가격**이 붙습니다 |

한 번 정한 색은 **다음 캡처에도 그대로 기억**합니다.

---

## 무엇을 읽어 주나요

| 지표 | 읽는 것 |
|---|---|
| 🕯️ **캔들** | 봉 개수, 마지막 봉이 양봉/음봉, 최근 방향, 구간 최고·최저 사이 어디쯤인지 |
| 📉 **이동평균선** | 선마다 방향, 가격과의 위·아래, **이격도**, 선 순서(정배열·역배열·혼조), **골든/데드크로스가 몇 봉 전인지** |
| 🎈 **볼린저밴드** | **%B**(밴드 안 위치), 밴드 폭이 좁은지 넓은지(**스퀴즈·확장**), 폭이 벌어지는 중인지, 중심선 방향, **밴드 타기** |
| ☁️ **일목균형표** | 가격이 구름 **위·속·아래** 어디인지, 구름 두께, 양운·음운, **앞쪽 구름 전환**, 전환선·기준선의 호전·역전과 교차 |

마지막에 **얼마나 잘 읽었나** 칸이 나옵니다. 각 색을 가로 폭의 몇 %에서 찾았는지 알려 주고,
너무 적게 잡히면 다시 찍으라고 말해 줍니다.

## 어떻게 읽는 건가요 (원리)

가격 데이터를 받아오는 게 아니라 **그림 자체를 읽습니다.**

**1. 어떤 색이 쓰였는지 모읍니다.** 범례의 작은 색 네모(■)를 찾고, 그림에서 많이 쓰인 색을 모읍니다.
검은 선도 여기서 얻습니다.

**2. 캔들을 찾습니다.** 세로로 길쭉한 덩어리가 넓게 흩어져 있는 색 두 가지가 캔들입니다.
거래량 칸은 따로 떨어져 있어 가려내고, 봉 간격이 일정한 구간만 남겨
현재가 딱지·차트 안 글씨를 걸러냅니다. 시가가 앞 봉 종가와 이어지는 쪽을 **양봉**으로 봅니다.

**3. 몇 일선인지 맞춥니다.** 캔들에서 읽은 종가로 **5·10·20…일 이동평균과 전환선·기준선·구름을
직접 계산**해서, 어느 선과 겹치는지 견줍니다. 그래서 글자를 못 읽어도
"이 주황선은 10일선(오차 1%)"까지 나옵니다.
화면에 보이는 봉보다 긴 이평선(60·120·200일)은 계산으로 확인할 수 없어,
**범례에 놓인 차례대로** 흔히 쓰는 기간을 넣고 *짐작*이라고 표시합니다.

**4. 나머지를 가려냅니다.** 위아래 두 줄에 그 사이가 차 있으면 구름 또는 볼린저밴드입니다.
가운데가 20일선과 맞으면 볼린저, 아니면 구름입니다.
가로 눈금선(모든 칸에서 같은 줄에 있는 색)은 지표에서 뺍니다.

**5. 선을 따라갑니다.** 픽셀 하나는 **가장 가까운 색 하나에게만** 줍니다.
(증권사 차트는 캔들 색과 이평선 색이 비슷한 경우가 많아 이렇게 해야 섞이지 않습니다)
가려진 곳은 앞뒤로 이어 메우고, 가격 눈금을 맞추면 픽셀 높이를 실제 가격으로 바꿔 계산합니다.

그래서 선이 겹치거나 색이 아주 비슷하면 조금씩 어긋날 수 있습니다.
**같은 색을 두 지표에 쓰고 있으면**(예: 기준선과 60일선이 둘 다 초록) 섞여 읽히고,
그럴 때는 결과에 그렇다고 적어 둡니다.
확대해서 캡처할수록, 선 색이 서로 다를수록 잘 읽힙니다.

## 이 앱이 하지 않는 것

- 사라 · 팔라 · 오를 것이다 · 내릴 것이다 같은 **판단과 예측**
- 종목 추천, 목표가, 손절가

보조지표는 모두 **지나간 값으로 만든 계산**입니다.
이 앱의 설명은 지표를 읽는 일반적인 방법일 뿐이고, 투자 판단과 그 결과는 **본인의 몫**입니다.
