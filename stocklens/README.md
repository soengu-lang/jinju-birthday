# StockLens AI 🔎

**종목을 찍어 주는 AI가 아니라, 내 투자 논리를 검증해 주는 AI 애널리스트**입니다.

관심 종목을 넣으면

1. 재무데이터로 **AI Score**(성장·수익·밸류·재무·모멘텀)를 계산하고
2. **Bull / Base / Bear** 적정가치 시나리오를 만들고
3. 내가 적은 **투자 논리(Thesis)** 를 가정·리스크로 쪼개 저장해 두고
4. 시세·증권사 추정치·뉴스가 바뀔 때마다 **"어제와 무엇이 달라졌나"** 만 골라 보여 주고
5. 그 변화가 내 논리에 닿는지 점검합니다.

그리고 **AI에게 질문**하면 그 종목의 실제 데이터가 같이 전달됩니다.
"삼성전자 지금 비싼 거야?", "영업이익이 20% 떨어지면 적정주가는?", "SK하이닉스랑 비교해 줘".

앱 파일은 `index.html` **하나**뿐입니다. 서버도, 회원가입도 없고, 기록은 이 폰 안에만 있습니다.

## 원칙: 재무데이터 → 계산 모델 → 점수 → AI 설명

점수와 목표가는 **AI가 느낌으로 만들지 않습니다.** 아래 계산은 모두 `index.html` 안의 순수 함수이고,
종목 화면의 **"왜 이 점수인가요?"** 를 펼치면 어떤 숫자로 계산했는지 그대로 나옵니다.

### AI Score (0~100)

| 항목 | 가중치 | 보는 것 |
|---|---|---|
| 성장성 | 25 | 최근 3년 매출 연평균 성장률, 직전 연도 영업이익 증가율, 올해 추정 영업이익 증가율 |
| 수익성 | 25 | 영업이익률 수준, ROE, 영업이익률 추세 |
| 밸류에이션 | 20 | PER vs 자기 과거 평균, PER vs 동일업종, 추정 PER, PBR, 배당수익률 |
| 재무건전성 | 15 | 부채비율, 당좌비율, 순이익 흑자 여부 |
| 모멘텀 | 15 | 20·60·120일선 대비 위치, 3개월 수익률, 52주 범위 내 위치 |

빠진 데이터가 있으면 그 항목은 빼고 나머지로 계산하며, **데이터 커버리지 %** 를 같이 표시합니다.

### 적정가치 시나리오 — EPS × PER

- 기준 EPS: 증권사 추정 EPS (없으면 최근 연간 EPS)
- PER: **그 회사 PER 중앙값 · 동일업종 PER · 지금 PER** 셋을 견줘 기준 PER 을 정하고, 그 위아래로 Bull / Bear 를 잡습니다.
  이익이 급감한 해에는 PER 이 수십 배로 튀어서 평균을 쓰면 목표가가 터무니없어지기 때문입니다 (실제로 그런 버그가 있었습니다)
- Bull 은 EPS +15%, Bear 는 EPS −20% 가 기본값. **슬라이더로 바꾸면 즉시 다시 계산**됩니다
- 적자 기업은 이 방식이 맞지 않는다고 표시합니다

### Risk Monitor

데이터로 잴 수 있는 것만 별 개수(1~5)로 보여 줍니다: 밸류에이션 부담, 재무 레버리지, 이익 변동성, 매출 역성장, 52주 고점권 과열, 증권사 커버리지 부족.
"경쟁력 약화" 같은 정성 리스크는 투자 논리의 **깨뜨릴 수 있는 것** 칸에 적어 두면 뉴스 제목과 맞춰 봅니다.

### 변화 감지 (Change Detection)

앱을 열 때마다 종목별로 그날의 스냅샷(시세·PER·목표가 컨센서스·추정 영업이익·추정 EPS·투자의견·점수·재무제표 기준 시점·뉴스)을 남기고,
**이전 날 스냅샷과 비교**해 다음만 골라냅니다.

| 감지 | 기준 |
|---|---|
| 주가 급변 | 하루 ±4% 이상 (며칠 만이면 ±8%) |
| 목표주가 컨센서스 | ±2% 이상 (±5% 이상이면 HIGH) |
| 올해 영업이익 추정치 | ±2% 이상 (±5% 이상이면 HIGH) |
| 추정 EPS | ±3% 이상 |
| 투자의견 평균 | ±0.2 이상 |
| 새 재무제표 반영 | 연간 데이터의 최신 열이 바뀜 |
| AI 점수 | ±4 이상, 가장 크게 움직인 항목 표시 |
| 주요 뉴스 | 처음 보는 기사 중 실적·가이던스·공시·수주·자사주·배당·규제·점유율 등의 키워드가 있는 것 |

홈에는 LOW 등급을 뺀 상위 3개만 올라옵니다. **정보를 더 주는 게 아니라 읽을 것을 줄이는** 화면입니다.

### 투자 논리 (Thesis Tracker)

종목 화면 → **✍️ 직접 쓰기** (또는 AI 키가 있으면 **✨ AI가 논리 만들기**).
가정·리스크 한 줄마다 키워드를 뽑아 두고, 새 뉴스 제목에 그 키워드가 나오거나 부정적 변화(목표가·추정치 하향 등)가 감지되면
홈에 **🚨 투자 논리 점검 필요** 가 뜹니다. **🔎 AI 점검**을 누르면 AI가 데이터와 뉴스로 확신도를 다시 매기고 이유를 적습니다. 확신도 변화는 이력으로 남습니다.

## 📊 우리집 자산 앱과 연동

**보유 수량·평단가를 읽어 오면 이 앱이 "내 계좌 기준"으로 바뀝니다.** 자산 앱에는 아무것도 쓰지 않고 **읽기만** 합니다.

| 연동 방법 | 하는 법 |
|---|---|
| **이 폰** (추천) | 자산 앱과 주소가 같아서 바로 읽습니다. 첫 화면의 **🔗 이 폰의 자산 앱과 연동** 한 번이면 끝 |
| **다른 폰 · 배우자** | ⚙️ → 📊 우리집 자산 연동 → "배우자와 공유하는 방" 선택. 자산 앱 ⚙️의 방 이름·프로젝트 ID·API 키를 넣습니다 (자산 앱이 가계부 방을 읽는 것과 같은 방식) |

연동하면 이렇게 달라집니다.

- **보유 종목이 관심종목으로** 들어옵니다 (계좌가 여러 곳이면 한 종목으로 합쳐서, 숨긴 종목은 빼고)
- **홈**: 국내주식 평가금액·손익·수익률·오늘 변동액, 전체 자산 중 국내주식 비중, **업종 쏠림 경고**(한 업종에 40% 이상)
- **종목**: 💼 내 보유 카드 — 수량·평단·평가액·손익·비중, 그리고 **시나리오가 맞으면 내 계좌가 얼마가 되는지**(Bull/Base/Bear·증권사 목표가·자산 앱에 적어 둔 내 목표가·손절가별 평가금액과 손익)
- **Risk Monitor**에 **내 포트폴리오 집중도**가 추가됩니다 (국내주식의 몇 %인지)
- **변화 감지**가 **많이 들고 있는 종목 순서**로 정렬됩니다
- **논리 탭**: 보유 중인데 왜 샀는지 안 적어 둔 종목을 모아서 알려 줍니다
- **투자일지**: 매수 기록을 열면 평단가·수량이 자동으로 채워집니다
- **AI 질문**: 실제 비중·손익·업종 집중도가 함께 전달돼서 "비중이 너무 큰 종목 있어?", "업종이 겹치는 건?" 에 진짜 숫자로 답합니다

평가금액은 **이 앱이 방금 받은 시세**로 다시 계산하므로 자산 앱보다 최신입니다.
국내·미국 주식이 아닌 자산(코인·금·부동산 등)은 전체 자산 합계에만 쓰이고 추적하지 않습니다.
공유 방으로 읽을 때는 시세 캐시가 공유되지 않아 국내주식 외 자산의 평가액을 모를 수 있고, 그 개수를 알려 줍니다.

## AI 는 어떻게 붙나요

⚙️ 설정에 **내 API 키**를 넣습니다. 서버가 없으므로 폰에서 AI 회사로 직접 부릅니다.

| 회사 | 기본 모델 | 키 발급 |
|---|---|---|
| Anthropic Claude (기본) | `claude-opus-5` | console.anthropic.com |
| OpenAI | `gpt-5` | platform.openai.com |
| Google Gemini | `gemini-2.5-pro` | aistudio.google.com |

키는 이 브라우저 저장소에만 있고 질문할 때 그 회사 서버로만 갑니다. 키가 없어도 **점수·시나리오·변화 감지·논리 저장은 다 됩니다.** AI 키가 필요한 건 질문·해석·AI 논리 생성·AI 점검·브리핑·복기입니다.

AI 에게는 다음 원칙이 시스템 프롬프트로 들어갑니다.

- 사라/팔라를 말하지 않는다. 대신 "이 논리가 맞으려면 무엇이 사실이어야 하고, 무엇이 그것을 깨뜨리나"를 밝힌다
- 함께 보낸 데이터(JSON)에만 근거하고, 없는 숫자는 지어내지 않는다
- 점수·목표가는 앱의 계산 결과이므로 바꾸지 않고 해석만 한다
- 답 끝에 어떤 데이터를 썼는지 "근거:" 로 적는다

## 🇺🇸 미국주식

**엔비디아·애플처럼 미국 종목도 담을 수 있습니다.** 한글 이름("엔비디아")이나 티커(NVDA) 둘 다 검색됩니다.
값은 **달러로** 보여 주고, 보유 손익은 원화로도 함께 적습니다(환율은 자산 앱에서 가져옵니다).

| | 국내 | 미국 |
|---|---|---|
| 시세·일봉 | 네이버증권 | 야후 파이낸스 (막히면 네이버 해외종목) |
| PER·PBR·목표가·배당 | 네이버 투자지표 | 야후 요약 |
| 재무 | 네이버 연간·분기표 (억원) | 야후 손익계산서·재무상태표에서 계산 (백만 달러) |
| 뉴스 | 네이버 종목뉴스 | 야후 뉴스 (영문) |
| 단위 | 원 | 달러 |

**미국주식에서 약한 곳**: 과거 PER 기록이 없어서 시나리오의 Base 가 현재가와 비슷하게 나옵니다.
그래서 화면에 그렇다고 적어 두고 **증권사 목표가와 견주라**고 안내합니다. 국내처럼 분기 재무는 없습니다.

자산 앱에 담긴 미국주식도 함께 추적되고, 비중·업종 쏠림은 **원화로 환산해서** 국내주식과 같이 계산합니다.

## 시세·재무·뉴스는 어디서 오나요

국내는 네이버증권 모바일 API(시세, 투자지표, 컨센서스, 연간·분기 재무, 일봉, 뉴스), 미국은 야후 파이낸스를 읽습니다.
정적 페이지라 브라우저에서 바로 부르면 막히기 때문에 공개 중계를 순서대로 시도하고, 다 막히면 마지막으로 받아 둔 데이터를 보여 줍니다.

**공개 중계는 실제로 자주 죽습니다.** (확인된 예: allorigins·codetabs 시간 초과, corsproxy HTTP 401)
그래서 **내 구글 계정에서 도는 중계**를 하나 만드는 것이 사실상 유일하게 확실한 방법입니다.

**📡 중계 만들기 (3분, 무료)** — 시세를 못 받으면 홈에, 그리고 ⚙️ → 📡 데이터에 버튼이 있습니다.
코드 복사 → [script.new](https://script.new) 붙여넣기 → 배포(웹 앱 · 액세스 **모든 사용자**) → 나온 URL 붙여넣기 →
**시험해 보기**를 누르면 그 자리에서 삼성전자 시세를 불러 보고 되는지 알려 줍니다. 되면 저장하고 바로 시세가 붙습니다.
안 되면 이유(권한·주소·배포)에 맞는 안내가 나옵니다.

**우리집 자산 앱에 중계 주소가 있으면 자동으로 물려받습니다.** 둘 다 없으면 점검 화면이 그렇다고 알려 줍니다.

### 🩺 시세 점검 — 안 붙을 때

⚙️ → 📡 데이터 → **🩺 시세 점검** (시세를 못 받으면 홈에도 버튼이 나옵니다).
삼성전자를 시험 삼아 불러 보면서 **중계 주소 → 인터넷 → 중계 경로마다 → 투자지표·재무·뉴스·일봉**을 하나씩 확인하고,
어디서 막혔는지 초록/빨강으로 보여 줍니다. **📋 결과 복사**로 복사해서 보내 주시면 무엇이 문제인지 바로 알 수 있습니다.

가져오는 방식도 이렇게 버팁니다.

- 시세는 **두 곳**(모바일 API → 실시간 폴링)을 차례로 시도합니다
- 시세를 먼저 받아 중계가 살아 있는지 확인한 뒤에 나머지(재무·뉴스·일봉)를 부릅니다
- **내 중계**(구글 스크립트)는 느릴 수 있어 20초까지 기다리고 한 번 더 시도합니다
- 공개 중계는 두 번 막히면 그 새로고침 동안 건너뜁니다
- 재무·뉴스가 빠져도 시세와 점수는 나옵니다 (빠진 항목은 종목 화면에 적힙니다)

## 이 앱이 하지 않는 것

- 사라 · 팔라 · 오를 것이다 · 내릴 것이다 같은 **판단과 예측**
- 종목 추천, 자동매매, 증권사 연결, 실시간 차트, 커뮤니티
- 데이터에 없는 숫자를 AI가 만들어 내는 것
