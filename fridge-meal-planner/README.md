# 우리집 냉장고 식단표 🧊🍱

냉장고에 있는 재료를 기록해 두면 → **1주일 식단**을 짜 주고 → **부족한 것만 골라 장보기 목록**을 만들고 →
레시피는 **메뉴판**처럼 모아 보고(유튜브·인스타 링크 바로 이동) → **한 달 식비**까지 정리해 주는 앱입니다.

앱 파일은 `index.html` **하나**뿐입니다. 서버도, 설치도, 회원가입도 없습니다.

## 어떻게 여나요

| 방법 | 하는 법 |
|---|---|
| 폰에서 쓰기 (추천) | GitHub Pages를 켜고 `https://<사용자명>.github.io/jinju-birthday/fridge-meal-planner/` 접속 → 브라우저 메뉴에서 **홈 화면에 추가** 하면 앱처럼 열립니다 |
| PC에서 바로 | `index.html` 파일을 더블클릭 |

> 💡 **홈 화면에 추가**를 해 두면 주소창 없이 전체화면으로 뜨고, 아이콘도 생겨서 실제 앱처럼 쓸 수 있어요.

## 다섯 개의 탭

### 🧊 냉장고 — 있는 재료 기록
- 이름·수량·단위·소비기한을 넣으면 분류(단백질/채소/양념…)는 **자동으로** 잡힙니다.
- 소비기한이 가까우면 `D-2`, 지났으면 `기한 지남` 배지가 붙고 목록 맨 위로 올라옵니다.
- `＋ 계란` 같은 **빠른 추가 칩**으로 자주 사는 건 한 번에 담습니다.
- 같은 재료를 또 담으면 수량이 합쳐집니다(예: 계란 6개 + 10개 = 16개).
  이름이 **정확히 같을 때만** 합쳐지므로 두부와 두부면, 계란과 계란말이는 따로 관리됩니다
  (괄호 설명과 띄어쓰기는 무시해요: `소고기 우둔살 (호주산)` = `소고기우둔살`).

### 🍱 이번 주 — 식단 짜기
- **🧊 냉장고로 자동 추천**: 지금 있는 재료로 가장 많이 만들 수 있는 메뉴를 우선 배치합니다.
  - 재료가 얼마나 맞는지(커버리지), **소비기한 임박 재료를 쓰는지**, 같은 메뉴가 연달아 오지 않는지를 함께 계산해요.
  - 배치할 때마다 재고를 가상으로 차감하므로, 소고기 400g으로 소고기 요리 3일이 잡히는 일이 없습니다.
- **🔁 로테이션**: 즐겨찾기(❤️) 메뉴가 3개 이상이면 그 안에서, 아니면 전체 메뉴를 순서대로 돌립니다.
- 요일 카드의 드롭다운으로 **직접 골라도** 됩니다. 오늘 날짜는 주황색으로 표시돼요.
- 아래 **주말 밀프렙 조리 순서**는 오래 걸리는 요리부터 세워 줍니다(순차 시간 vs 병렬 시간도 계산).

### 📖 메뉴판 — 레시피 보관함
- 카드마다 칼로리·단백질·조리시간·태그가 보이고, ▶(유튜브)·📷(인스타) 아이콘을 누르면 **저장한 링크로 바로 이동**합니다.
- 링크를 저장 안 했어도 `레시피 영상 보기`를 누르면 그 메뉴 이름으로 **유튜브 검색**이 열립니다.
- 레시피를 열면 **인분 ±** 에 따라 재료량이 자동 환산되고(`밀프렙 5일치` 버튼 한 번이면 5일치 계산),
  **냉장고에 없는 재료에는 `부족` 표시**가 붙습니다.
- **요리 모드**로 STEP 1 → 2 → 3 넘겨 가며 만들 수 있어요.

### 🛒 장보기 — 부족한 것만
- 이번 주 식단에 **필요한 총량 − 냉장고 재고 = 사야 할 양**을 자동 계산합니다.
  (`소고기 우둔살 필요 600g · 보유 400g → 200g` 처럼요)
- 분류별로 묶여 있어 마트 동선대로 담기 좋습니다. **📋 목록 복사**로 카톡에 붙여넣을 수도 있어요.
- 장을 보고 체크한 뒤 **✅ 담은 것 냉장고에 넣기**를 누르면
  → 냉장고에 자동 입고(소비기한도 분류별로 자동 설정) → 이어서 **얼마 썼는지 묻는 창**이 떠서 식비까지 한 번에 기록됩니다.

### 💳 식비 — 한 달에 얼마 썼나
- 장보기 / 외식 / 배달 / 카페·간식으로 나눠 기록합니다.
- 이번 달 총액, **지난달 대비 얼마 더 썼는지/아꼈는지**, 예산 대비 %, 이 속도면 월말에 얼마가 될지,
  분류별 막대와 주차별 그래프를 보여 줍니다.
- ‹ › 로 지난달도 볼 수 있어요.

## 📷 캡처를 넣으면 자동으로 저장되는 원리

메뉴판의 **📷 캡처로 레시피 추가**를 누르면 두 갈래로 인식합니다.

1. **텍스트 붙여넣기 (가장 정확, 항상 됨)**
   인스타 캡션이나 유튜브 더보기 내용을 복사해서 붙여넣고 `✨ 자동으로 채우기`를 누르면
   **제목 · 칼로리 · 단백질 · 조리시간 · 기준 인분 · 재료와 수량 · 조리 단계 · 유튜브/인스타 링크**를 뽑아냅니다.
   - `소고기 우둔살 400g   시금치 200g` 처럼 **두 칸으로 붙어 있어도** 각각 잡아냅니다.
   - `1인분 기준 360kcal` 의 "1인분"은 영양성분 기준이라 기준 인분으로 오해하지 않고, `재료 (4인분 환산)` 쪽을 씁니다.

2. **이미지에서 글자 인식 (OCR)**
   캡처 이미지를 넣고 `🔍 이미지에서 글자 자동 인식`을 누르면 한국어 OCR(tesseract.js)이 글자를 읽어
   위와 같은 방식으로 칸을 채웁니다.
   - 처음 한 번은 한국어 인식 데이터를 내려받느라 20~30초 걸리고, **인터넷 연결이 필요**합니다.
   - 손글씨체나 배경 위 작은 글자는 틀릴 수 있어요. 자동으로 채워진 뒤 **눈으로 확인하고 고치면** 됩니다.
   - 인식이 안 되면 캡션을 복사해서 1번 방법을 쓰세요.

넣은 이미지는 **메뉴판 카드의 사진**으로도 그대로 쓰입니다. 캡처만 모아도 나만의 메뉴판이 돼요.
사진은 저장 공간을 아끼려고 자동으로 축소(가로세로 최대 760px)해서 보관합니다.

### 더 정확하게 하고 싶다면 (선택)
Claude API의 이미지 인식을 붙이면 OCR보다 훨씬 정확하게 뽑을 수 있습니다.
`캡처 이미지 → Claude에게 "이 레시피를 JSON으로 정리해줘" → 그 JSON을 그대로 저장`하는 방식이며,
이때는 API 키가 필요하고 키가 브라우저에 저장되므로 **개인 기기에서만** 쓰는 걸 권합니다.
지금 앱은 키 없이도 완전히 동작하도록 만들어 두었습니다.

## 👨‍👩‍👧 가족과 함께 쓰기 (선택)

기본은 폰 한 대에만 저장되지만, **Firebase**를 연결하면 두 폰이 같은 냉장고·식단·장보기·식비를 함께 봅니다.
남편이 마트에서 장보기 항목을 체크하면 아내 폰에서도 사라지는 식이에요.

**한 사람만** 아래 준비를 하면 되고, 나머지 식구는 **초대 링크만 열면** 끝입니다.

### 준비 (한 번만, 약 5분 · 무료)

1. [console.firebase.google.com](https://console.firebase.google.com) 접속 → 구글 로그인
2. **프로젝트 만들기** → 이름 아무거나 (애널리틱스는 꺼도 됩니다)
3. 왼쪽 **빌드 → Firestore Database** → **데이터베이스 만들기** → 위치는 기본값
4. **규칙** 탭을 아래 내용으로 바꾸고 **게시**

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /rooms/{roomId}/{document=**} {
      allow read, write: if roomId.size() >= 16;
    }
  }
}
```

5. ⚙️ **프로젝트 설정** → 아래로 내려 **웹앱(`</>`)** 추가 → 나오는 `firebaseConfig` 값을 통째로 복사
6. 앱에서 ⚙️ → **가족과 공유 시작하기** → 복사한 값 붙여넣기 → **연결하고 방 만들기**
7. 나오는 **초대 링크를 배우자에게 카톡으로** 전송 → 상대는 링크를 열고 **참여**만 누르면 끝

> 홈 화면에 추가한 앱처럼 **주소창이 없어 링크를 열 수 없는 곳**에서는,
> ⚙️ → **🔗 초대 링크로 참여하기** 에 링크를 붙여넣으면 똑같이 참여됩니다.

### 어떻게 동작하나요
- 사진을 뺀 전체 데이터가 `rooms/{방}/state/core` 문서 하나에, 레시피 사진은 `rooms/{방}/img/{id}`에 따로 저장됩니다
  (사진까지 한 문서에 넣으면 Firestore의 문서당 1MB 한도에 걸리기 때문입니다).
- 화면을 보고 있을 때만 **15초마다 문서 1건**을 확인하고, 바뀌었을 때만 내려받습니다.
  가족 두세 명이 쓰는 정도는 무료 한도 안에 넉넉히 들어옵니다.
- 앱을 다시 열거나 화면을 켤 때도 한 번 확인합니다.

### 몇 대까지 되나요
**대수 제한 없습니다.** 내 아이폰·아이패드, 배우자 아이폰·아이패드 모두 같은 방에 넣을 수 있어요.
다만 **기기마다 한 번씩** 참여시켜야 하고, 같은 기기라도 **사파리와 홈 화면 앱은 따로** 참여시켜야 합니다
(저장소가 서로 다르기 때문입니다). 한 번 참여시키면 그다음부터는 자동입니다.

### 미리 알아 두실 점
- **동시에 같은 걸 고치면 나중에 저장한 쪽이 이깁니다.** 변경은 약 1초 뒤 바로 올라가서 겹칠 틈이 좁지만,
  둘이 동시에 식단을 짜면 한쪽 내용이 덮일 수 있어요.
- **인터넷이 끊긴 곳(마트 지하 등)에서 적은 내용은 폰에 남아 있다가 연결되면 올라갑니다.**
  아직 못 올린 내 변경이 있으면 남의 내용을 먼저 받아 덮어쓰지 않도록 막아 뒀어요.
- **초대 링크를 아는 사람은 우리 방에 들어올 수 있습니다.** 가족에게만 보내세요.
  (링크에는 우리 방 주소와 접속 키가 들어 있고, 위 보안 규칙은 그 방 바깥은 막아 줍니다.)
- 공유를 끄면(⚙️ → 공유 끄기) 그 폰은 다시 혼자 쓰는 상태가 되고, 지금까지 받은 기록은 그대로 남습니다.
- 공유가 꺼져 있으면 **네트워크 요청을 한 건도 보내지 않습니다.**

## 데이터는 어디에 저장되나요

- 모든 기록은 **그 브라우저 안(localStorage)** 에만 저장됩니다. 가족 공유를 켜지 않으면 서버로 아무것도 보내지 않고, 인터넷이 끊겨도 돌아갑니다.
- 대신 **폰을 바꾸거나 브라우저 데이터를 지우면 사라집니다.** 설정(⚙️)에서 가끔
  **⬇️ 백업 파일 내려받기**를 해 두고, 새 기기에서 **⬆️ 불러오기** 하세요.

### ⚠️ 브라우저가 다르면 기록도 따로입니다
카카오톡 내장 브라우저, 사파리, 크롬, 홈 화면에 추가한 앱은 **각각 다른 저장소**를 씁니다.
카톡에서 열어 기록하다가 사파리로 열면 처음 상태로 보이는 게 정상이에요(기록이 사라진 게 아닙니다).

옮기는 법 — ⚙️ 설정에서:
1. 원래 쓰던 브라우저에서 **📋 백업 내용 복사**
   (복사가 막히는 인앱 브라우저에서는 수동 복사창이 뜹니다 → 길게 눌러 복사)
2. 옮길 브라우저에서 **📥 붙여넣어 복원하기** → 붙여넣고 복원

파일 내려받기가 되는 환경이라면 백업 파일로 옮겨도 됩니다.
**가족 공유(Firebase)를 켜 두면** 브라우저·기기가 달라도 같은 방을 보므로 이 문제가 아예 없어집니다.
